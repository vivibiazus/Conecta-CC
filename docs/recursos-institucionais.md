# Recursos Institucionais e Externos — ConectaCC

Este documento registra recursos, sistemas, páginas e canais relevantes para o ConectaCC.

O objetivo é mapear o que já existe antes de criar novas funcionalidades.

Um dos princípios centrais do projeto é:

> **O ConectaCC deve conectar, organizar e contextualizar recursos existentes, e não reconstruir aquilo que já possui uma fonte oficial adequada.**

---

# 1. Objetivo do mapeamento

O mapeamento de recursos serve para:

- identificar onde as informações já existem;
- evitar duplicação desnecessária;
- facilitar o acesso dos estudantes;
- decidir onde cada recurso deve aparecer dentro do ConectaCC;
- confirmar URLs antes da implementação;
- diferenciar recursos institucionais de conteúdos colaborativos;
- apoiar a futura definição do módulo ou área de Informações e Serviços.

---

# 2. Status utilizados

Cada recurso poderá possuir um dos seguintes estados:

- ✅ **Confirmado** — recurso e URL já identificados.
- 🟡 **A confirmar** — sabemos que o recurso existe, mas ainda precisamos confirmar a URL ou a forma correta de utilização.
- 🔎 **A mapear** — recurso ainda precisa ser localizado ou analisado.
- 💡 **A decidir** — recurso conhecido, mas ainda precisamos decidir onde aparecerá no ConectaCC.

# 7. Possível área “Informações e Serviços”

A auditoria final do protótipo identificou uma questão importante:

recursos como:

- SUAP;
- Moodle;
- Painel de Sistemas;
- Instituto de Informática;
- professores;
- ementas;

não possuem atualmente um local único no protótipo.

A concepção original do projeto previa uma dimensão de orientação e acesso a informações.

Durante a simplificação do MVP, essa área deixou de existir como item independente da navegação.

Essa decisão ainda precisa ser revisada.

# 8. Alternativas para Informações e Serviços

Algumas possibilidades que poderão ser avaliadas:

## Alternativa A — Área própria

Criar futuramente uma área:

**Informações e Serviços**

reunindo acessos importantes.

### Vantagem

Centralização clara.

### Desvantagem

Adiciona mais um item à navegação.

---

## Alternativa B — Distribuir pelos módulos existentes

Exemplos:

Moodle e ementas  
→ Estudos

Estágios e extensão  
→ Oportunidade

Arena Games, WhatsApp e Instagram  
→ Comunidade

SUAP e Painel  
→ Home ou outro espaço de acesso rápido.

### Vantagem

Evita novo módulo.

### Desvantagem

Alguns recursos podem não possuir destino natural.

---

## Alternativa C — Área de acessos rápidos

Criar um bloco ou componente transversal:

**Acessos úteis**

sem necessariamente criar um novo módulo completo.

Essa possibilidade poderá ser avaliada após o mapeamento dos recursos.

---

# 9. Critérios para decidir onde um recurso aparece

Para cada recurso, perguntar:

1. Para que o estudante utiliza?
2. Existe relação clara com Estudos?
3. Existe relação clara com Oportunidade?
4. Existe relação clara com Comunidade?
5. É um serviço transversal?
6. O estudante precisa acessá-lo com frequência?
7. O ConectaCC precisa explicar o recurso ou apenas fornecer acesso?
8. A fonte é oficial?
9. A URL é estável?
10. Existe risco de duplicar informação institucional?

# 11. Regras para links externos

Links institucionais devem:

- utilizar fonte confirmada;
- abrir em nova guia quando levarem para outro ambiente;
- possuir indicação visual de link externo;
- não utilizar URLs inventadas;
- ser revisados periodicamente quando o projeto estiver em uso real.

No protótipo, URLs ainda não confirmadas utilizam estados não clicáveis como:

**Link oficial a confirmar**

---

# 12. Diferença entre recurso institucional e conteúdo colaborativo

## Institucional

Origem:

- IFSul;
- Câmpus Passo Fundo;
- Instituto de Informática;
- sistema oficial;
- setor institucional.

O ConectaCC funciona como acesso/contexto.

## Colaborativo

Origem:

- estudantes;
- comunidade.

Exemplos:

- material;
- publicação;
- oportunidade indicada.

Conteúdos colaborativos passam por Moderação antes de serem disponibilizados.

# 14. Princípio final

O objetivo deste levantamento não é colocar o maior número possível de links no ConectaCC.

O objetivo é facilitar a jornada do estudante.

Um recurso deve entrar quando contribuir para:

- encontrar informações;
- compreender onde realizar determinada ação;
- descobrir oportunidades;
- acessar recursos acadêmicos;
- conectar-se à comunidade.

O ConectaCC deve funcionar como uma camada de conexão e orientação sobre o ecossistema existente.
