# Fundação técnica, Cadastro, Login e Home — plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam checkbox (`- [ ]`) para acompanhamento.

**Objetivo:** montar a base do ConectaCC (Docker, CI/CD, imagem de produção) e entregar Cadastro, Login, Logout e Home com layout global funcionando de ponta a ponta.

**Arquitetura:** API REST Laravel 13 em `/api/v1` com Sanctum em modo SPA (cookie de sessão + CSRF), consumida por uma SPA React servida na mesma origem. No desenvolvimento, o Vite (porta 5173) faz proxy para o Laravel; em produção, a SPA compilada fica em `backend/public/spa` e uma rota de fallback do Laravel devolve o `index.html`.

**Stack:** PHP 8.4, Laravel 13, Sanctum, Pest, Pint, Larastan (nível 6), Scramble, PostgreSQL 17, React 19 + TypeScript, Vite, Tailwind v4, shadcn/ui, React Router, TanStack Query, React Hook Form, openapi-fetch, Docker Compose, `serversideup/php:8.4-fpm-nginx`, GitHub Actions, Render.

**Spec:** `docs/specs/2026-10-12-fundacao-design.md`. Leia a spec antes de cada tarefa; este plano argumenta a partir dela.

## Restrições globais

- PHP 8.4; Laravel 13; Node 24; npm; PostgreSQL 17; Larastan nível 6.
- Papéis exatamente: `ALUNO`, `MODERADOR`, `ADMINISTRADOR`. Toda conta criada pelo Cadastro nasce `ALUNO`.
- `ALLOWED_EMAIL_DOMAINS=academico.ifsul.edu.br` (lista separada por vírgula, comparação exata do texto após o último `@`, sem diferenciar maiúsculas).
- E-mail sempre gravado em minúsculas e sem espaços nas pontas.
- `TERMS_VERSION=0.1`.
- Sessão: driver `database`, `SESSION_LIFETIME=10080`, sem "Lembrar de mim".
- Limites: Login 5/min por e-mail+IP; Cadastro 5/min por IP; resposta 429 com "Muitas tentativas. Tente novamente em X segundos.".
- Mensagens exatas (spec §7 e §8): "E-mail ou senha incorretos.", "Informe seu nome completo.", "Informe um endereço de e-mail válido.", "Use seu e-mail institucional do IFSul.", "Não foi possível criar uma conta com este e-mail. Se você já possui cadastro, entre.", "Use pelo menos 8 caracteres.", "As senhas informadas não coincidem.", "Os Termos de participação foram atualizados. Leia e aceite novamente.", "Conta criada. Entre com seu e-mail e senha.", "Não foi possível conectar ao ConectaCC. Verifique sua conexão e tente novamente.", "Não foi possível carregar algumas informações agora. Tente novamente.", "Esta área ainda está em construção.".
- Sem link "Esqueci minha senha".
- Sentry desligado sem DSN; sem PII; usuário só pelo ID.
- Nome visual sempre "ConectaCC".
- Commits em Conventional Commits, terminando com `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`. Sem push.
- Seeders nunca rodam em produção.

## Foco de revisão

Entradas que a spec implica e que um usuário real vai encontrar. Cada linha tem teste na tarefa indicada.

1. E-mail digitado com maiúsculas ou espaços (`  Ana.Silva@Academico.IFSUL.edu.br `) no Cadastro e no Login → tratado como o mesmo e-mail em minúsculas (Tarefas 5 e 6).
2. Nome completo só com espaços → "Informe seu nome completo." (Tarefa 5).
3. Domínios parecidos (`@ifsul.edu.br`, `@sub.academico.ifsul.edu.br`, `@academico.ifsul.edu.br.evil.com`) → recusados (Tarefa 5).
4. Dois cadastros simultâneos com o mesmo e-mail (duplo clique, duas abas) → o segundo recebe a mensagem de e-mail já cadastrado (422), não erro 500 (Tarefa 5).
5. `promote-user` roda num repositório público: o e-mail do estudante não pode aparecer no log do Actions → o comando não imprime o e-mail e o workflow mascara a entrada (Tarefas 7 e 16).

export class ApiError extends Error {
  constructor(
    public readonly status: number,
    message: string,
    public readonly fieldErrors: FieldErrors = {},
  ) {
    super(message);
  }
}

export class NetworkError extends Error {}

type FetchResult<T> = { data?: T; error?: unknown; response: Response };

export async function call<T>(request: Promise<FetchResult<T>>): Promise<T> {
  let result: FetchResult<T>;
  try {
    result = await request;
  } catch {
    throw new NetworkError('network');
  }
  if (result.response.ok) return result.data as T;
  const body = (result.error ?? {}) as { message?: string; errors?: FieldErrors };
  throw new ApiError(result.response.status, body.message ?? '', body.errors ?? {});
}

function readCookie(name: string): string | null {

import type { FieldValues, Path, UseFormSetError } from 'react-hook-form';
import type { FieldErrors } from '@/lib/api/errors';

// coloca os erros 422 do servidor nos campos do formulário; devolve os que não têm campo
export function applyFieldErrors<T extends FieldValues>(
  setError: UseFormSetError<T>,
  fieldErrors: FieldErrors,
  fields: readonly Path<T>[],
): FieldErrors {
  const rest: FieldErrors = {};
  let focused = false;
  for (const [key, messages] of Object.entries(fieldErrors)) {
    if ((fields as readonly string[]).includes(key)) {
      setError(key as Path<T>, { type: 'server', message: messages[0] }, { shouldFocus: !focused });
      focused = true;
    } else {
      rest[key] = messages;
    }
  }
  return rest;
}

  const createAccount = async (termsVersion: string) => {
    const values = getValues();
    try {
      await registerAccount.mutateAsync({ ...values, terms_version: termsVersion });
      navigate('/login', { state: { registeredEmail: values.email.trim().toLowerCase() } });
    } catch (error) {
      setTermsOpen(false);
      if (error instanceof ApiError && error.status === 422) {
        const rest = applyFieldErrors(setError, error.fieldErrors, FIELDS);
        const other = Object.values(rest)[0]?.[0];
        if (other) setProblem({ kind: 'message', message: other });
      } else if (error instanceof ApiError && error.status === 429) {
        setProblem({ kind: 'message', message: error.message });
      } else {
        setProblem({ kind: 'network' });
      }
    }
  };

  const emailError =
    errors.email?.message === EMAIL_TAKEN ? (
      <>
        Não foi possível criar uma conta com este e-mail. Se você já possui cadastro,{' '}
        <Link to="/login" className="font-semibold underline underline-offset-2">
          entre
        </Link>
        .
      </>
    ) : (
      errors.email?.message
    );

  return (
    <AuthLayout>
      <h1 className="font-display text-4xl font-bold text-foreground sm:text-5xl">Crie sua conta</h1>
      <p className="mt-3 text-lg text-muted-foreground">
        Use seu e-mail institucional para participar da versão de testes do ConectaCC.
      </p>

      <form noValidate onSubmit={openTerms} className="mt-10 space-y-6">
        {problem?.kind === 'message' && <FormAlert variant="danger">{problem.message}</FormAlert>}
        {problem?.kind === 'network' && (
          <FormAlert
            variant="danger"
            action={
              <button type="button" onClick={() => openTerms()} className="font-semibold underline underline-offset-2">
                Tentar novamente
              </button>
            }
          >
            Não foi possível conectar ao ConectaCC. Verifique sua conexão e tente novamente.
          </FormAlert>
        )}

        <TextField
          label="Nome completo"
          autoComplete="name"
          maxLength={120}
          hint="Também será seu nome de exibição inicial. Você pode alterá-lo no Perfil."
          error={errors.name?.message}
          {...register('name', { validate: (value) => value.trim() !== '' || 'Informe seu nome completo.' })}
        />
        <TextField
          label="E-mail institucional"
          type="email"
          autoComplete="email"
          placeholder="seuemail@..."
          error={emailError}
          {...register('email', {
            required: 'Informe um endereço de e-mail válido.',
            pattern: { value: EMAIL_PATTERN, message: 'Informe um endereço de e-mail válido.' },
          })}
        />
        <TextField
          label="Senha"
          type="password"
          autoComplete="new-password"

          error={errors.password?.message}

            minLength: { value: 8, message: 'Use pelo menos 8 caracteres.' },

          label="Confirmar senha"

        <Button type="submit" className="h-12 w-full text-base font-semibold">
