# Catálogo de disciplinas, Perfil e card "Complete seu perfil" — plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam checkbox (`- [ ]`) para acompanhamento.

**Objetivo:** carregar o catálogo da Matriz 2023, entregar ver/editar o próprio Perfil e mostrar o card "Complete seu perfil" na Home.

**Arquitetura:** o catálogo vem de um JSON versionado gravado no banco por uma migration de dados. O Perfil é um recurso único do usuário logado (`GET/PUT /api/v1/profile`): os campos ficam em `users` e as disciplinas atuais numa tabela de ligação. O front ganha a página `/perfil` (visualização e edição, que é marcada na URL por `?editar`), dois componentes reaproveitáveis (tags e busca de disciplinas) e um guarda de saída para alterações não salvas.

**Stack:** a da fundação (Laravel 13, Pest, Scramble, PostgreSQL 17, React 19, React Router 8, TanStack Query, React Hook Form, openapi-fetch, Tailwind v4, shadcn/ui).

**Spec:** `docs/specs/2026-10-19-perfil-design.md`. Leia a spec antes de cada tarefa; os números de tela citados são páginas dos PDFs listados no topo dela.
